Gérer la boutique

Vos modifications (articles, collections, réglages) sont enregistrées directement sur votre site GitHub et deviennent visibles par tous vos clients 1 à 2 minutes après la publication.

Comment obtenir ma clé d’accès ? (une seule fois)
  1. Connectez-vous à GitHub puis ouvrez github.com/settings/personal-access-tokens/new.
  2. Token name : « Boutique Dar Ennekhwa ». Expiration : la durée de votre choix.
  3. Repository access : « Only select repositories » → choisissez adamelkenz/adamelkenz.github.io.
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Cliquez sur Generate token, copiez la clé et collez-la ci-dessus.

La clé reste uniquement dans ce navigateur. Ne la partagez avec personne. Sur un ordinateur partagé, cliquez sur « Déconnexion » après usage.
